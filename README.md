# Design-of-a-4x4-SRAM-circuit-

- Bộ nhớ SRAM (Static Random Access Memory) đóng vai trò rất quan trọng trong các hệ
thống mạch tích hợp hiện đại nhờ tốc độ truy xuất cực kỳ nhanh và khả năng lưu trữ trạng
thái mà không cần cơ chế làm mới như DRAM (Dynamic Random Access Memory).
- Một hệ thống bộ nhớ SRAM 4x4 hoàn chỉnh không chỉ bao gồm ma trận ô nhớ 6T (bao
gồm 6 transistor) mà còn cần tích hợp các mạch ngoại vi như: mạch tiền nạp (precharge
circuit), mạch điều khiển ghi (write driver), và bộ khuếch đại cảm nhận (sense amplifier).
